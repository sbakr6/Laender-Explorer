# Länder Explorer

## Projektbeschreibung
Der Länder Explorer ist ein Python-Programm, mit dem man Informationen über verschiedene Länder suchen und anzeigen kann.

Das Programm verwendet eine Web-API, um die Länderinformationen aus dem Internet abzurufen.

## Funktionen
- Länder nach ihrem Namen suchen
- Hauptstadt anzeigen
- Einwohnerzahl anzeigen
- Mehrere Länder nacheinander suchen
- Fehlermeldung bei unbekannten Ländern
- Eigene Angaben für Kurdistan anzeigen
- Grafische Benutzeroberfläche (GUI)

## Verwendete Technologien
- **Python** – Programmiersprache
- **requests** – Zum Abrufen der API-Daten
- **tkinter** – Für die grafische Oberfläche
- **JSON** – Zum Verarbeiten der Daten
- **GitHub** – Zum Speichern des Projekts

## Verwendete API
Ich verwende die API von [countries.dev](https://countries.dev/).

Mit dieser API kann ich Informationen über verschiedene Länder abrufen.

## Installation und Start
1. Python installieren.
2. Das Repository herunterladen.
3. Im Projektordner `pip install -r requirements.txt` ausführen.
4. Das Programm mit `python main.py` starten.
